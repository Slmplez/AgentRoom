# 工作区变更、行内评论与自动保存

持久 Web 与桌面现在共用文件审阅入口。宿主必须显式指定可编辑目录；已有 `--agent-workspace` 只读配置不会开启写入权限。

```powershell
node server.cjs --persistent --data-dir E:/AgentRoomData --editor-workspace E:/TrustedRepo --port 4331
```

`--editor-workspace` 应指向用户信任的本地 Git 仓库根目录。此参数不启动 Agent，也不自动保存或改动仓库。桌面连接同一个宿主：

```powershell
npx electron . --persistent --persistent-url http://127.0.0.1:4331
```

打开房间右上角“工作区变更”。文件列表包含已暂存、未暂存及未跟踪的净变化；点击“刷新”重新读取。未启用编辑目录时不显示此入口。Git 缺失、非仓库、数量/大小超限与暂无变更分别明确提示；不会把截断结果当成完整差异。忽略文件与子模块内部变更不包含，重命名按删除与新增显示。

- **行内评论**：点击代码行旁的 ＋，或展开“添加评论”选择左右侧及行号。评论保存在本机数据库，绑定当前补丁版本；不发送给 Agent。刷新为新补丁后不会把旧评论搬到新行。
- **编辑文件**：打开完整磁盘文本，停止输入约 700 ms 后自动保存。界面显示等待、保存中、已保存或错误状态；输入法组合期间暂停保存。Ctrl+S 可立即尝试保存。
- **冲突与恢复**：磁盘被其他程序修改时停止覆盖，保留草稿，可比较磁盘内容。选择采用磁盘版本会先备份草稿。断线、回执丢失或重启后继续使用原请求标识核查，不用新标识盲目重放。
- **只读项**：删除文件保留原始差异及评论；二进制、链接、硬链接、不支持的路径和超过 256 KiB 的文件显示原因。已有普通 UTF-8 文件可编辑；此功能不会按补丁创建或删除文件。

读取最多 60 个变更文件、合计 1 MiB 的完整补丁。原版本与当前文本均限制为 256 KiB。Git 使用工作区外的固定绝对可执行路径；内容差异由已校验的快照生成，不由 Git 重新读取可变工作文件。

保存检查文件版本和身份，并使用同目录原子替换与持久回执。对任意外部进程，这不是操作系统级的原子比较并替换：最终检查到重命名之间仍有竞态。宿主会拒绝与尚未确认停止的本机 Agent 任务并发保存；能力应仅用于可信本地工作区。

生产链路验收脚本：`npx electron scripts/verify-file-review-production-ui.cjs --disable-gpu`。它使用隔离 Git 与数据库，覆盖正式公共 Client、Cookie/来源检查、Web/桌面评论同步、真实磁盘字节、超过 128 KiB 的保存、外部冲突及重启草稿恢复。不会操作已有 4331 用户工作区。
