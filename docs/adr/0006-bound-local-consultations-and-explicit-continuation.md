# 本机咨询有明确预算，继续执行需要可核对的原请求

2026-10-31 用户移除多人登录和 Teams，并授权制定剩余咨询、表单及附件规则。当前交付仅使用本机单 owner；历史规划中的多人和外部会话要求不再作为本轮前置条件。保留已有的唯一任务 Owner、来源追溯和结果未知语义。

真实咨询由 owner 明确指定已登记的 Agent，每个问题最多三个接收者、每个分派最多启动一次引擎，深度为一。持久队列按 FIFO 选择可运行项，咨询总并发为二、每 Agent 为一；队列、执行时限和问题有效期均有限制。次数、时间与并发是可以在宿主强制执行的预算；供应商计费存在延迟，因此不把这些限额表述为美元金额保证。普通提及和模型建议不产生递归调度。

进程重启后，未开始的咨询暂停，已开始但结果不可确认的咨询保留为未知。只有明确恢复尚未启动的请求才可继续；不重放未知执行。采纳建议只记录决定，向原任务投递仍须验证当前问题版本与存活引擎身份，并遵循原答复回执。表单答复保存和向任务投递也是两个可分别核对的行为，避免把数据库提交成功误报为引擎已经继续。

这一选择牺牲无人干预的自动恢复，换取可说明的调用成本、任务归属与副作用边界。具体可调整限额及验收以 GitHub #23/#37 和 #24 的实施票据为准；本记录不是功能已经实现的证明。
