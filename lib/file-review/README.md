# 文件审阅边界（#44）

服务仅接受宿主 `resolveScope(input, caller)` 返回的根目录、授权范围和真人身份；请求不能提供 root。宿主须先验证登录身份、房间成员及工作区，写入权限使用独立的编辑工作区配置，不能从只读 Agent 工作目录推断。

支持已有、单链接、无符号链接/重解析路径、256 KB 以内 UTF-8 普通文件。绝对路径、反斜杠、父目录、ADS、Windows 保留名和 `.git` 路径被拒绝。UTF-8 BOM、CRLF 和 POSIX 文件 mode 保留。文件不因差异内容自动创建/删除。

保存使用读取 hash 和根目录 hash、同 key 持久记录及原子 rename。先落 prepared 草稿，再复核磁盘 hash/文件身份，替换并记录完成。崩溃恢复只在磁盘等于原版本或目标版本时完成同 key 请求，否则返回冲突，绝不盲目重放。磁盘与 SQLite 不是同一事务；跨程序在最终检查与 rename 之间仍有操作系统级竞态，不宣称对任意外部进程提供原子 CAS。宿主需将此能力限定为用户自己信任的本地工作区。

评论绑定工作区、房间、真人、文件、补丁 digest、侧及原始行号；对旧补丁评论不会重定位到新的代码。评论为本地私有批注，不生成聊天消息或 Agent 指令。

共享入口由 #38/#39 所有者交接后串行接线：AgentRoomClient → transport → 已认证宿主 → 本服务。独立服务、契约、编辑状态机及 UI 在交接期间可独立验证；未接线时产品必须明确不可用，不能把本地草稿称为磁盘保存。


同一标签页内，相同文件的编辑器共用保存控制器和单一初始读取。关闭/重开不会让旧保存回执或旧 readFile 覆盖新草稿；控制器无使用者时排空队列后释放。不同标签页分开存储草稿，真实文件以读取版本检测竞争。已完成写操作清除 prepared 全文，只保留幂等回执；未完成记录保留原文和草稿用于恢复核查。

验证状态：15 项服务/状态机测试，以及真实 Cookie 认证 HTTP + Electron 界面验证通过。覆盖目录替换、双服务旧版本写入、替换后回执丢失、外部更新后禁止恢复覆盖、输入法、晚到保存和晚到初始读取。共享宿主尚未装配，不能把这些隔离测试当作生产能力已经上线。
