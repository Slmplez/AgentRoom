# 文件审阅边界（#44）

服务仅接受宿主 `resolveScope(input, caller)` 返回的根目录、授权范围和真人身份；请求不能提供 root。宿主须先验证登录身份、房间成员及工作区，写入权限使用独立的编辑工作区配置，不能从只读 Agent 工作目录推断。

支持已有、单链接、无符号链接/重解析路径、256 KB 以内 UTF-8 普通文件。绝对路径、反斜杠、父目录、ADS、Windows 保留名和 `.git` 路径被拒绝。UTF-8 BOM、CRLF 和 POSIX 文件 mode 保留。文件不因差异内容自动创建/删除。

保存使用读取 hash 和根目录 hash、同 key 持久记录及原子 rename。先落 prepared 草稿，再复核磁盘 hash/文件身份，替换并记录完成。崩溃恢复只在磁盘等于原版本或目标版本时完成同 key 请求，否则返回冲突，绝不盲目重放。磁盘与 SQLite 不是同一事务；跨程序在最终检查与 rename 之间仍有操作系统级竞态，不宣称对任意外部进程提供原子 CAS。宿主需将此能力限定为用户自己信任的本地工作区。

评论绑定工作区、房间、真人、文件、补丁 digest、侧及原始行号；对旧补丁评论不会重定位到新的代码。评论为本地私有批注，不生成聊天消息或 Agent 指令。

共享入口已完成串行接线：AgentRoomClient → 持久 transport → Cookie/来源校验代理 → Bearer 认证宿主 → 本服务。显式 editorWorkspace 决定 fileReview capability；未启用时入口隐藏且服务拒绝请求。使用说明见 docs/FILE-REVIEW.md。


同一标签页内，相同文件的编辑器共用保存控制器和单一初始读取。关闭/重开不会让旧保存回执或旧 readFile 覆盖新草稿；控制器无使用者时排空队列后释放。不同标签页分开存储草稿，真实文件以读取版本检测竞争。已完成写操作清除 prepared 全文，只保留幂等回执；未完成记录保留原文和草稿用于恢复核查。

验证状态：15 项服务/状态机测试，以及真实 Cookie 认证 HTTP + Electron 界面验证通过。覆盖目录替换、双服务旧版本写入、替换后回执丢失、外部更新后禁止恢复覆盖、输入法、晚到保存和晚到初始读取。正式宿主也已装配；另用隔离真实 Git/数据库验证了 Web 与桌面的生产公共 Client 链路。已有用户测试服务的版本更新由集成会话负责。

## 工作区变更读取

新增 `changes` 请求只接受工作区/房间身份，通过同一授权 resolver 得到显式编辑根。只执行固定 Git 参数，无 shell，不接收客户端路径/修订/命令。禁用 external diff、textconv、fsmonitor、clean/process filter 和可选 index 锁，不运行 Agent、不保存文件。继承环境中的 `GIT_*` 清除，系统/用户 Git 配置不参与此读取；仓库本地过滤器显式禁用。宿主仍需绑定用户信任的本地仓库。

返回完整变更文件状态及有界完整补丁；UTF-8 普通文件可编辑，删除文件只读，二进制/超大/链接/合并冲突以明确原因列出。未跟踪和首次提交前文件包含在内，忽略文件及子模块内部变化不包含。上限为 60 文件、补丁合计 1 MiB、状态列表 64 KiB、总计 10 秒，超限报错而不截断；JSON 转义后的响应体仍有界。读取结束复核状态和 HEAD，但不声称跨进程/跨文件原子快照。

Git 可执行文件从宿主 PATH 的绝对目录定位，规范化后排除工作区内部路径，使用固定绝对路径启动；不让 Windows 在工作区搜索 `git.exe`。当前文件内容仅来自服务的已验证读取，原版本来自 Git blob；在工作区外的临时快照目录计算文本差异，并在结束后清理。Git diff 不重新打开可被替换的工作文件，防止验证后路径被换为外部硬链接而输出外部内容。原版本同样限制为 256 KiB UTF-8；只有元数据变化时保留文件状态说明。

新增 9 项临时 Git 仓库测试通过（含括号路径、惰性同名可执行文件标记和验证后硬链接替换），与原 15 项合计 24 项。测试未执行不受信代码，未读取真实用户文件。持久页面按钮、公共 Client 与宿主已接线；另有 4 项真实 HTTP 公共 Client 测试覆盖能力/房间隔离、丢失回执、响应校验及换房间晚到结果。详见 HANDOFF.md。
